## Official NOAA Directives & Guidelines

When publishing research or managing public funds, NOAA scientists must comply with institutional data sharing and software management policies. 

Please refer to the official guidelines below regarding code availability, open-source compliance, and public access mandates:

* 🔗 **[NOAA Environmental Data Management Committee (EDMC) Directives](https://www.noaa.gov)** 
* 🔗 **[NOAA Data Access Procedural Directives](https://www.noaa.gov)**

### Summary of Best Practices for NOAA Repositories:
1. **Public vs. Private:** Keep active research repositories private during data collection and analysis phases, moving to public status upon manuscript submission.
2. **Disclaimer:** Ensure your public repository includes the standard NOAA software disclaimer in its `README.md` file.
3. **Archiving:** Use permanent version tags (like `v1.0`) when code is used to generate figures for an officially published NOAA technical memorandum or peer-reviewed paper.
