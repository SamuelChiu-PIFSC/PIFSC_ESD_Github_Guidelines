# PIFSC ESD GitHub Guidelines

Welcome to the central documentation hub for version control, data workflows, and repository management. This workspace is designed specifically for PIFSC ESD scientists, researchers, and developers to ensure our code remains secure, organized, and easily maintainable.

---

## 🗺️ Documentation Directory

We have organized our guidelines into specific sections to support your workflow. Use the sidebar navigation or the summaries below to find exactly what you need:

### 🚀 Setup & Core Concepts
* **[Getting Started]({{ site.baseurl }}/getting-started/)**: Your very first stop. Learn how to set up your official agency GitHub account, build a secure local workstation folder structure, and install Git on your machine.
* **[Git & GitHub Fundamentals]({{ site.baseurl }}/fundamentals/)**: Learn the core concepts of version control. This page explains the difference between Git and GitHub, the local file lifecycle (Staging vs. Committing), and why these practices are essential for scientific reproducibility.

### 🔒 Workflows & Governance
* **[Cybersecurity Boundaries]({{ site.baseurl }}/cybersecurity/)**: Crucial security rules. Learn our strict compliance guidelines regarding hardcoded credentials, file-locking errors on shared network drives, and data governance constraints.
* **[Project Workflows]({{ site.baseurl }}/project-workflows/)**: Understand how data streams between environments. See how we balance remote cloud buckets, local sandboxes, and long-term network storage archives without losing track of changes.

### 🛠️ Advanced Skills & Compliance
* **[Handling Merge Conflicts]({{ site.baseurl }}/merge-conflicts/)**: A dedicated guide to dealing with history collisions. Learn how to read Git conflict markers and confidently stitch conflicting lines of code back together.
* **[PIFSC Requirements]({{ site.baseurl }}/noaa-requirements/)**: Review institutional mandates, public code access laws, and specific repository policies tailored to tracking code within our agency.

### 📝 Quick Reference Sheets
* **[CLI Cheat Sheet]({{ site.baseurl }}/cli-cheatsheet/)**: A handy reference for the core Terminal/Git Bash commands you will use every day.
* **[RStudio Cheat Sheet]({{ site.baseurl }}/rstudio-cheatsheet/)**: For our R users—how to seamlessly utilize Git, commit changes, and push branches directly through the RStudio graphical user interface.

### 🎓 Future Reference & Growth
* **[GitHub Advanced]({{ site.baseurl }}/github-advanced/)**: Take your skills to the next level once you are comfortable with the basics. This section details automation hooks, advanced repository settings, and collaborative branching strategies for scaling multi-investigator projects.
